# Sample dataset — source & licence

`channelmix-sample.csv` is a conversion of a **real, publicly published advertising dataset**. It is not
generated by ChannelMix. It is only loaded into a workspace when a user explicitly asks for it
(`POST /api/v1/datasets/sample/import` / the "Load sample dataset" button).

| | |
|---|---|
| Dataset | **Online Advertising Digital Marketing data** ("Online Advertising Performance Data") |
| Publisher | n. aniruddhan on Kaggle |
| URL | https://www.kaggle.com/datasets/naniruddhan/online-advertising-digital-marketing-data |
| Licence | **MIT** (as displayed in the Kaggle dataset's *License* field; verified 2025-10-28 by the ChannelMix maintainers) |
| Files | `online_advertising_performance_data.csv` (≈967 kB, 15,408 rows) + `Online Advertising Performance Data.txt` (data dictionary) |
| Content | Daily online-display advertising performance of an anonymised advertiser ("Company X") served through one ad network ("Advert Firm A"), **1 April 2020 – 30 June 2020**, USD. Rows are segmented by campaign (3), user-engagement tier, banner size and publisher placement (`abc`, `def`, `ghi`, `jkl`, `mno`, unknown). |
| Raw file SHA-256 | `8504cc53019bd9cfc83d478c2872a11160b6ddbbb6d2699d718dd9c489014d81` (the copy we converted; Kaggle requires a login for direct downloads, so the file was obtained from a public GitHub mirror of the same Kaggle dataset and checked against the published row count) |

## Data dictionary (from the dataset's own `.txt`)

> Day: date of the advertising campaign. Campaign: a segmentation variable set by Company X. User Engagement: level of
> engagement of targeted users. Banner: ad size served by "Advert Firm A". Placement: publisher space (website/app)
> where the ad is served. Displays: number of ads served. Cost: the price paid by "Advert Firm A" to serve the ads to
> the publisher. Clicks: number of clicks. Revenue: the price paid by Company X to "Advert Firm A" for the clicks.
> Post Click Conversions: on-site transactions within 30 days after a click. Post Click Sales Amount: monetary value of
> those transactions.

## How it was converted (`convert_oapd.py`)

ChannelMix is the **advertiser's** dashboard, so columns are mapped from Company X's point of view:

| ChannelMix field | Source | Note |
|---|---|---|
| `day` | `month` + `day` (year 2020) | |
| `channel` | — | constant `other`: the data comes from a single anonymised display network, so we do **not** label it Google/Meta/… |
| `campaign` / `external_id` | `campaign_number` × `placement` | e.g. `Campaign 1 / placement ghi` → `campaign1-ghi`; engagement tier and banner size are summed away |
| `impressions` | Σ `displays` | |
| `clicks` | Σ `clicks` | |
| `conversions` | Σ `post_click_conversions` | |
| `spend` | Σ `revenue` | what Company X paid the network (CPC billing); the `cost` column is the network's own publisher cost and is dropped |
| `revenue` | Σ `post_click_sales_amount` | attributed on-site sales (30-day post-click window) |

Result: **1,248 rows, 18 campaigns, 91 days** (`2020-04-01` → `2020-06-30`). Totals: spend ≈ $276k, attributed sales ≈ $32.7M
(the dataset's attributed-sales figures are large relative to media cost; we report them as published).

Regenerate with:

```bash
python -m app.datasets.convert_oapd /path/to/online_advertising_performance_data.csv > app/datasets/channelmix-sample.csv
```
